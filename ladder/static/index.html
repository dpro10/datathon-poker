    How it works

    1. Download the starter kit (or just the bot template) and write your bot.
    2. Test it locally: python3 -m arena check my_bot
    3. Upload it here. It plays a 20-hand test first, then joins the ladder.
    4. Upload new versions under new names (diego-v2, diego-v3) and compare them.

    Fair matches

    • Every deal is played twice with the seats swapped, so both bots get the same cards.
    • Rating is Elo from match wins. bb/100 is big blinds won per 100 hands.
